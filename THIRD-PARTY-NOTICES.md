## Development & build tools (not distributed)

The project is built and tested with Electron Builder (MIT), Inno Setup, Vitest
(MIT), Playwright (Apache-2.0), Stryker (Apache-2.0), ESLint (MIT), and other
lockfile-recorded tools. Development dependency licenses are not bundled into the
application because those packages are not distributed.

To regenerate a full dependency-license report:

```bash
npx license-checker --summary          # license totals
npx license-checker --excludePackages "$(node -p "require('./package.json').name")"
```
