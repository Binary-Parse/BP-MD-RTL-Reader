are hand-authored derivatives of Lucide's ISC-licensed `panel-left` / `panel-right`
geometry, with one solid interior path added — Lucide is an outline-only set and ships no
filled variant. They are covered by the Lucide notice above and live outside the
machine-generated sprite block.

The machine-readable source versions and SHA-256 hashes are in
`resources/vendor/vendor-manifest.json`. Complete license texts for these libraries
and the runtime dependency closure incorporated into their browser bundles are in
`resources/vendor/THIRD-PARTY-LICENSES.txt`. Run `npm run vendor:check` to verify
that committed assets still match the exact lockfile sources.

These assets are never fetched at application runtime. The unrelated, explicit
**Check for Updates…** command requests only GitHub public release metadata and does not
load a library or font.

## Development & build tools (not distributed)

The project is built and tested with Electron Builder (MIT), Inno Setup, Vitest
(MIT), Playwright (Apache-2.0), Stryker (Apache-2.0), ESLint (MIT), and other
lockfile-recorded tools. Development dependency licenses are not bundled into the
application because those packages are not distributed.

The reproducible development-dependency summary is
[`docs/dependency-license-inventory.json`](docs/dependency-license-inventory.json). It is
generated from every non-root `packages` entry in lockfile v3, records the exact
`package-lock.json` SHA-256, distinguishes lockfile entries from unique package names,
and surfaces missing `license` fields instead of guessing them. Verify or refresh it with
the repository-pinned Node runtime—no global tool or registry request is involved:

```bash
npm run license:inventory          # fail if the committed summary differs from the lock
npm run license:inventory:update   # regenerate after an intentional lockfile change
```
